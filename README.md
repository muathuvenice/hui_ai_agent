# Hui Thong Minh On-Chain - AI Agent Engine

He thong AI Agent dinh luong cho nen tang Hui phi tap trung tren mang Avalanche (Fuji Testnet).

## Cai dat va Chay thu

1. Khoi tao moi truong ao:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

2. Cau hinh bien moi truong:
   cp .env.example .env

3. Chay kiem thu (pytest):
   pytest -v

4. Chay demo AI Agent:
   python orchestrator.py
